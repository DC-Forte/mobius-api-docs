# mobius-api-docs

Published, partner-facing docs for Mobius's integration with Hiresense's AI-run interview
handoff API. Source of truth for these files lives in `chapter-interview-backend-go`
(`docs/mobius-integration.md`, `docs/openapi/mobius-handoff-v1.yaml`, `docs/CHANGELOG.md`) —
update there first, then copy over here and bump the version.

Published via GitHub Pages at the repo's Pages URL. Not linked from anywhere public and
excluded via `robots.txt` — reachable only by whoever has the exact URL.
